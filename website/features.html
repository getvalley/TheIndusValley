Every feature. One Valley.

The tools built into Valley 1.0, from everyday essentials to controls that put you in charge.

Search and start

  • Smart SearchSearch the web directly from the homepage, with quick access to recent searches and favourite destinations.
  • Customisable start pageUse the homepage as a launch point for search and frequently used destinations.

Read and understand

  • Reader ModeExtract the main article into a focused reading view.
  • Reader appearance controlsAdjust font and display settings while reading.
  • Webpage translationTranslate supported pages to understand more across languages.
  • Page cleanupRemove selected distracting elements for a cleaner view.
  • Page zoomPinch to zoom, or use the floating controls with a reset option.
  • Desktop siteRequest the desktop version when a wider layout helps.

Tabs

  • Tab overviewSee open pages in a dedicated overview and move between them.
  • Tab groupsOrganise open tabs into groups instead of one long list.
  • Swipe between tabsMove between adjacent tabs with a horizontal swipe.
  • Back and reloadGo back or reload from the browser controls.

Your things

  • FavouritesSave useful websites and return to them quickly.
  • Browsing historyReview previously visited pages, and delete entries you do not want.
  • Downloads managerDownload files and review their records and status.

Privacy

  • Tracker blockingBlock requests to domains on the built-in advertising and tracking list.
  • Third-party cookie controlOff by default, with an option to allow them when a site needs them.
  • Site exceptionsManage domains exempt from the blocklist.
Still evolving. Features can vary by website, Android version and app build. Reader Mode and translation depend on the page being compatible.
